# Direktori Public (Untuk Gambar Lokal)

Letakkan semua file gambar Anda (seperti `hero.jpg`, `profil.jpg`, `galeri1.jpg`) ke dalam folder ini.
Dalam React (Vite), file yang ada di dalam folder `public` bisa diakses langsung menggunakan tanda slash `/`.

Contoh pemanggilan di kode:
`<img src="/profil.jpg" alt="Profil" />`
atau untuk Background:
`style={{ backgroundImage: "url('/hero.jpg')" }}`
